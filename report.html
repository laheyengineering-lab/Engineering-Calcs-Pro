Project Report

Collect calculation results from any calculator into one project and print them as a single document. Each entry is a snapshot taken when it was added; it does not change if you later edit the calculator inputs. Data is stored only in this browser.

Project Information

All fields are optional. Nothing is sent anywhere; the project is saved in this browser's local storage.

Printing opens the browser's print dialog; choose "Save as PDF" as the destination to create a PDF file.
