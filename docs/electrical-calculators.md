## Circuit Studio and shared graphics

Use native form controls to add or remove resistors, change each resistance and its unit, declare an open branch, set the ideal DC source voltage, and switch between series and parallel. Valid edits update the circuit, equivalent resistance, branch measurements, total power, and Kirchhoff checks. The schematic labels the actual configuration with source polarity, nodes, wires, resistor symbols, values, and current directions. The per-branch table gives the same solved values in text. Open **Show solution steps** to see the equation sequence.

The circuit engines solve defined topologies. The shared SVG renderer draws those configurations and plots solved time or frequency samples for RC, RL, and series RLC. Changes to the selected time or frequency move the chart marker. [Interactive diagram architecture](interactive-diagrams.md)

## Applicability

- **DC circuits** assume ideal sources and wiring and fixed, linear resistances. Signed voltage drops and branch currents follow their indicated references. Passive resistors dissipate power and sources may supply or absorb it. Circuit Studio covers a single series path or shared-rail parallel branches. The Kirchhoff tool covers the fixed two-source, two-loop topology drawn on its page.
- **DC wire calculations** apply to a stated current and symmetric return path. AWG converts nominal solid-round dimensions to area. For a cable with known conductor area, enter its nominal metal cross-section. The model excludes stranding, termination/contact resistance, and self-heating. The linear preset formula $\rho(T)=\rho_{20}[1+\alpha_{20}(T-20\,^\circ\mathrm{C})]$ applies from 0 to 100 °C in the calculator. Custom resistivity is used as supplied at the operating temperature. A drop greater than the source voltage indicates an infeasible passive-load operating point. Ampacity, building-code compliance, and branch-circuit protection require separate evaluation.
- **Transients** assume one linear storage element and constant component values after the step. For RC and RL, the time to 2% of the initial deviation is $-\tau\ln(0.02)$ and to 1% is $-\tau\ln(0.01)$. A circuit starting at its final state stays there. The RLC calculator covers steady state at each plotted frequency.
- **AC power** applies to single-phase sinusoidal waveforms. The steady-state convention is $e^{j\omega t}$ with voltage phase relative to current. Harmonic, distortion, and three-phase power require other models.
- **Speaker loads** are nominal for one channel. Real impedances change with frequency, and a real amplifier's voltage can vary with the load. The analysis gives an idealized power estimate. Compatibility, clipping and speaker power handling require manufacturer data and the actual operating conditions.
