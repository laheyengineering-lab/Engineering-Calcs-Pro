Press Fit Calculator

Analyze shaft-and-hub interference fits using elastic Lamé thick-cylinder theory. Calculate interface pressure, hoop stresses, press force, and friction torque capacity.

Engineering Theory

Engineering Context

An interference fit creates contact pressure because the shaft is larger than the hub bore: the shaft expands the hub bore and the hub constrains the shaft. The resulting pressure transmits torque and axial load by friction. Common uses include gears on shafts, pulleys, bearings, wheels, bushings, rotors, sleeves, and permanent mechanical joints.

This is a simplified, preliminary elastic calculation. It is not an ISO fit-selection tool; you supply the actual diametral interference.

Governing Equations

\[ \delta_r = \frac{\Delta d}{2} = u_h + u_s \]
\[ p = \frac{\delta_r}{c\left[\frac{1}{E_h}\left(\frac{b^2+c^2}{b^2-c^2}+\nu_h\right)+\frac{1}{E_s}\left(\frac{c^2+a^2}{c^2-a^2}-\nu_s\right)\right]} \]
\[ \sigma_{\theta,h} = p\,\frac{b^2+c^2}{b^2-c^2} \qquad \sigma_{\theta,s} = -p\,\frac{c^2+a^2}{c^2-a^2} \]
\[ F_{press} = \mu p \pi d L \qquad T_{capacity} = \frac{\mu p \pi d^2 L}{2} \]
\[ FoS_h = \frac{S_{y,h}}{\sigma_{\theta,h}} \qquad FoS_s = \frac{S_{y,s}}{\left|\sigma_{\theta,s}\right|} \]

For a solid shaft \(a = 0\), so the shaft term becomes \((1-\nu_s)/E_s\) and \(\sigma_{\theta,s} = -p\). The shaft hoop stress is compressive (negative).

Variable Definitions

  • \(d\), \(c = d/2\) = interface diameter / radius
  • \(D\), \(b = D/2\) = hub outer diameter / radius
  • \(d_i\), \(a = d_i/2\) = shaft bore diameter / radius (0 for solid)
  • \(\Delta d\) = diametral interference (shaft OD − hub bore ID)
  • \(\delta_r\) = radial interference
  • \(E_h, E_s\) = hub / shaft Young's modulus
  • \(\nu_h, \nu_s\) = hub / shaft Poisson's ratio
  • \(p\) = interface (contact) pressure
  • \(\sigma_{\theta,h}\), \(\sigma_{\theta,s}\) = hoop stress at hub bore / shaft surface
  • \(\mu\) = assumed interface friction coefficient
  • \(L\) = engagement length
  • \(S_y\) = yield strength

Assumptions & Limitations

  • Linear elastic, isotropic material behavior; elastic deformation only
  • Uniform nominal interface pressure and perfect cylindrical geometry
  • The nominal interference supplied by the user is used directly
  • No surface roughness / asperity flattening correction
  • No local chamfer or end-effect correction
  • No thermal residual stress and no plastic interference
  • No stress concentration from keyways, grooves, shoulders, reliefs, etc.
  • Friction coefficient is user supplied
  • Torque and press-force results represent ideal friction capacity
  • Actual fit design should account for manufacturing tolerances and applicable fit standards
  • Only Lamé interface hoop stress is reported; no 3D / von Mises analysis

Worked Example

Given: d = 50 mm, Δd = 0.05 mm, D = 100 mm, solid shaft (di = 0), L = 50 mm, μ = 0.12, hub and shaft Carbon Steel.

Using the database values for Carbon Steel (E = 200 GPa, ν = 0.27). For identical hub and shaft materials with a solid shaft, Poisson's ratio cancels, so:

\[ p = \frac{25\times10^{-6}}{0.025\left[\frac{1}{E}\left(\frac{5}{3}+\nu\right)+\frac{1-\nu}{E}\right]} = \frac{E\,\delta_r}{c\,(8/3)} = 75.0\ \mathrm{MPa} \]

\[ \sigma_{\theta,h} = p\,\frac{5}{3} = 125.0\ \mathrm{MPa}, \quad F_{press} = 70.686\ \mathrm{kN}, \quad T_{capacity} = 1767.15\ \mathrm{N\cdot m} \]

Hub-material stress ratio against the database yield strength (170 MPa) gives FoSh = 170 / 125 = 1.36. Results differ when the materials differ or the shaft is hollow.

Engineering Considerations

  • Friction coefficient strongly depends on lubrication, surface finish, coating, temperature, assembly method and material pairing; do not treat 0.12 as universally valid.
  • The interference entered should reflect the actual (worst-case) tolerance condition, not just the nominal fit.
  • A factor of safety below 1 is a legitimate result and indicates the elastic hoop stress exceeds yield.
  • The factor of safety shown is an elastic/yield stress screening factor of safety only, not a complete press-fit design-code safety factor.
  • Rotating, thermal, fatigue and keyway effects are not included.
  • This calculator is not a replacement for a complete tolerance/fit design according to the applicable standard.
