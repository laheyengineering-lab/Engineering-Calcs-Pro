Save several scenarios for one calculator, compare them against a baseline, run a parametric sweep of one input and add the results to your project report. Studies are saved in this browser only; nothing is sent anywhere.

    Scenarios

    Each scenario stores its own inputs and a snapshot of its last calculated results. Editing inputs never changes other scenarios, and results only change when you press Recalculate.

    Parametric sweep

    A sweep recalculates the selected baseline scenario with one input varied; all other inputs are held at the baseline values. It is a model-based exploration, not an independent physical test. Maximum samples.
